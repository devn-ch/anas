ANAS 0.3.3 is a small follow-up to 0.3.2 for share users.

## Deleting a share user that has an SMB password

In 0.3.2 the delete removed the system account first and then tried to
remove the SMB password entry. Samba looks the entry up through the
system account, so on any user with an SMB password the second step
failed with "Failed to find a Unix account", the delete reported an
error, and the user stayed in the list until the page was reloaded.
The account itself was already gone.

The order is now reversed: the SMB entry is removed first, then the
account. If the SMB step fails, nothing has been removed. A delete
that fails for any reason now reloads the Share Users and Groups lists
so they show what is actually on the system.

## If you hit this on 0.3.2

The account is gone but its SMB password entry is still in Samba's
database, and it would come back if a user of the same name were
created later. Remove it on the node with:

```
pdbedit -x -u <name>
```

## Install / upgrade

Untar on the PVE node and run `sudo ./install.sh` (re-running over an
existing install is the upgrade path).
